What this is

An unofficial, community-generated API reference for the validator Go library, built from the library's own source at a pinned commit and generated with Sourcey. It is not affiliated with, endorsed by, or maintained by the upstream project. Upstream is the source of truth for the library; the generator is the source of truth for anything this site gets wrong about the source.
